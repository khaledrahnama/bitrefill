How it works

Three steps, zero clicks.

01

Parse intent

Extracts destination country, value type, and amount from plain English. No forms, no dropdowns.

02

Route intelligently

Picks the optimal instrument for the country — airtime, local gift card, or eSIM data — across 170+ countries.

03

Purchase autonomously

Creates an invoice, pays from balance, and polls until delivery. The redemption code is returned — no human in the loop.

Example intents

Just describe what you need.

🇳🇬
"Send $10 of value to my brother in Lagos"
→ Routes to MTN Nigeria airtime. Universally redeemable, widest coverage.
✈️
"I just landed in Bangkok, get me an eSIM with data"
→ Selects eSIM for Thailand. Activates on your device immediately.
🇵🇭
"Top up $20 for my sister in Manila"
→ Routes to Globe Prepaid Philippines. Matched closest denomination.
🎮
"Buy a $25 Steam gift card"
→ Purchases Steam gift card $25 autonomously. Code delivered instantly.
Get started

Run it in 3 steps.

1

Clone the repo

git clone https://github.com/khaledrahnama/bitrefill && cd value-router

2

Set your Bitrefill API key

Get a free key at bitrefill.com/account/developers, then:
export BITREFILL_API_KEY="your_key_here"

3

Run the agent

python agent.py "Send $10 to my friend in Lagos"
Add --test to run without spending real balance.
